# WEEKDAY SIGNAL

平日の朝・夜に2〜3分ずつ書くワーク「WEEKDAY SIGNAL」を、LINE から入力してスプレッドシートに溜める仕組み。

- 入力：LINE のトーク画面下のメニュー「朝」「夜」→ LINE の中で開く入力ページ（LIFF）
- 記録：Google スプレッドシート（1日1行）。Excel でも落とせる
- 声かけ：平日 7時・21時に、まだ書いていない人へボットから届く
- スタンプ：朝と夜の両方を書いた平日に ★。月の平日ぶん全部そろうと 🎁（ギフトは親が贈り、親の画面で「贈った」を押す）
- 親の画面：Google でログインして見る Web 画面（スプレッドシートを共有された人だけが見られる）

セットアップは **`docs/セットアップ手順.md`**。

## 構成

| 置き場所 | 中身 |
| --- | --- |
| `web/` | 入力ページ。GitHub Pages に置く静的ファイル。設問は `questions.json` から組み立てる |
| `gas/` | ボット（Google Apps Script）。LINE の Webhook、入力の保存、声かけ、スタンプ。スプレッドシートに紐づけて使う |
| `gas-parent/` | 親の画面（別の Apps Script）。見ている人の Google アカウントでスプレッドシートを開く |
| `gas/Shared.gs` | 列の定義・スタンプの数え方など。**`gas-parent/Shared.gs` と同じ中身**（テストが食い違いを見る） |
| `assets/richmenu.png` | トーク画面下のメニュー画像（2500×843） |
| `tests/` | `node tests/gas.test.js`（保存・連続日数・スタンプ・カードの形） |
| `preview/` | 見本の画面（`parent.html` は見本データで親の画面を開ける） |

## 決めたこと

- **設問は `web/questions.json` の1か所。** 紙のシートを直したら、ここを直す
- **朝と夜は同じ行に入る**（日付×LINE ユーザーで探して上書き）。片方を書き直しても、もう片方は消えない
- **返事はトークへの「完了」メッセージに対して返す。** 入力ページが送信後に本人名義で「【朝のチェック完了】…」を送り、ボットはそれに返信する。返信は LINE の無料通数に数えないため
- **秘密の値はコードに書かない。** Apps Script のスクリプト プロパティに置く（`config.js` の LIFF ID と URL は公開されてよい値）
- **Webhook は URL の合言葉で守る。** Apps Script はリクエストヘッダーを読めず、LINE の署名を確かめられないため
- **送信は LINE の ID トークンを LINE に確かめてから受ける。** `users` シートで有効な人だけ
- **親の画面はボットと別のプロジェクトにする。** ボットは匿名で呼べる形で公開しているので、同じ所に置くとログインを求められない。親の画面は「アクセスしているユーザーとして実行」にし、スプレッドシートの共有をそのまま閲覧権限にする
- **ギフトは自動で贈らない。** ボットから LINE ギフトを買う手段は無い。達成の記録（`gifts` シート）と「贈った」の記録だけを持つ

## 仮で決めたこと（変えられる）

| 項目 | 仮の決め | 変える場所 |
| --- | --- | --- |
| アンテナ | 複数選べる | `questions.json` の `antenna.multi` |
| 月曜の「今日あったもの」 | シートどおり最後が「発見した」 | `questions.json` の `feelings.by_day` |
| 金曜の夜 | 「自分に勝った?」と週のふりかえりの両方 | `web/app.js` の `nightForm` |
| 声かけ | 平日 7時・21時 | `gas/Code.gs` の `setup` |
| 土日 | 声かけなし。曜日を選べば金曜分などを後から書ける | 入力ページ上部の曜日ボタン |
