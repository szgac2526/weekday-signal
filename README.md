# Aestus

平日の朝・夜に2〜3分ずつ書くワーク「WEEKDAY SIGNAL」を、LINE から入力してスプレッドシートに溜める仕組み。
アプリ名は **Aestus**（ワークの名前は WEEKDAY SIGNAL のまま）。リポジトリ名 `weekday-signal` は、入力ページの URL に入っているので変えていない

- 入力：LINE のトーク画面下のメニュー「朝」「夜」→ LINE の中で開く入力ページ（LIFF）
- 記録：Google スプレッドシート（1日1行）。Excel でも落とせる
- 声かけ：平日、子どもごとに親が決めた時刻（初期値 7:00・21:00）に、まだ書いていない人へボットから届く
- セッション：朝と夜の両方を書いた平日で1つ。月の平日ぶんそろうとコンプリート（リワードは親が贈り、親の画面で「贈った」を押す）
- 見た目：黒基調の「トレーニングログ」。朝は WARM-UP（暖色の空と太陽）、夜は COOL-DOWN（紺の空と月）。曜日の色は紙のシートの5色
- 親の画面：Google でログインして使う Web 画面（スプレッドシートを共有された人だけ）。記録を見る・子どもと LINE をつなぐ・設問とごほうびを変える
- 兄弟：記録は子どもごと。LINE は1人1つでも、兄弟で1つを共有でもよい

セットアップは **`docs/セットアップ手順.md`**。

## 構成

| 置き場所 | 中身 |
| --- | --- |
| `web/` | 入力ページ。GitHub Pages に置く静的ファイル。設問は Apps Script から受け取る（`questions.json` は初期値と見本モード用） |
| `gas/` | ボット（Google Apps Script）。LINE の Webhook、入力の保存、声かけ、スタンプ。スプレッドシートに紐づけて使う |
| `gas-parent/` | 親の画面・管理画面（別の Apps Script）。見ている人の Google アカウントでスプレッドシートを開く |
| `gas/Shared.gs` | 列の定義・スタンプの数え方など。**`gas-parent/Shared.gs` と同じ中身**（テストが食い違いを見る） |
| `assets/richmenu.png` | トーク画面下のメニュー画像（2500×843） |
| `tests/` | `node tests/gas.test.js`（保存・連続日数・スタンプ・設問のそろえ方・兄弟と LINE・声かけ先） |
| `preview/` | 見本の画面（`parent.html` は見本データで親の画面・管理画面を開ける） |

## 決めたこと

- **設問は親が管理画面で変える**（`settings` シートに保存）。初期値は `web/questions.json` と `gas/Shared.gs` の `DEFAULT_QUESTIONS`（同じ中身。テストが見る）。保存は必ず `normalizeQuestions_` を通す。入力ページはその形を前提に組み立てるため
- **記録は子ども（子ID）ごと。LINE アカウントとは分ける。** 兄弟で1つの LINE を共有しても動くように。どの LINE からどの子が書けるかは親が決める（`children` シート）。子IDは名前と無関係（名前を変えても記録がつながる）。子は消さず「使う」を外す
- **朝と夜は同じ行に入る**（日付×子どもで探して上書き）。片方を書き直しても、もう片方は消えない
- **返事はトークへの「完了」メッセージに対して返す。** 入力ページが送信後に本人名義で「【朝のチェック完了】名前…」を送り、ボットは1行目の名前でどの子の分かを決めて返信する。返信は LINE の無料通数に数えないため
- **秘密の値はコードに書かない。** Apps Script のスクリプト プロパティに置く（`config.js` の LIFF ID と URL は公開されてよい値）
- **Webhook は URL の合言葉で守る。** Apps Script はリクエストヘッダーを読めず、LINE の署名を確かめられないため
- **送信は LINE の ID トークンを LINE に確かめてから受ける。** `users` シートで有効な LINE、かつその LINE につながった子の分だけ
- **声かけは15分ごとの見回り1本。** 子どもごとの時刻を過ぎていて、まだ書いておらず、今日まだ送っていないものを送る（時刻ごとにトリガーを作ると、時刻を変えるたびに作り直しが要るため）。時刻から3時間を過ぎたら送らない
- **同じ LINE・同じ時間帯の声かけは1通にまとめる。** 兄弟で共有していても2通にしない（無料の通数）。まだ書いていない子の名前を添える
- **その日の追加の質問は1列（「問い：答え」）。** 質問は親が後から変えるので、列を増やすと過去の行と意味がずれる
- **親の画面はボットと別のプロジェクトにする。** ボットは匿名で呼べる形で公開しているので、同じ所に置くとログインを求められない。親の画面は「アクセスしているユーザーとして実行」にし、スプレッドシートの共有をそのまま権限にする（閲覧者は見るだけ、編集者は設定も変えられる）
- **ギフトは自動で贈らない。** ボットから LINE ギフトを買う手段は無い。達成の記録（`gifts` シート）と「贈った」の記録だけを持つ

## 仮で決めたこと（変えられる）

| 項目 | 仮の決め | 変える場所 |
| --- | --- | --- |
| 設問の初期値 | 5曜日のシート（2026-10-07 版）どおり。アンテナは1つ選ぶ、QUEST は曜日の4つ＋自分で決める | 親の画面の「設問」 |
| 書き方シートとの違い | 書き方シートの「曜日ごとのアンテナ」「QUEST を自由に書く」は、曜日ごとに切り替えられる（初期値は使わない） | 親の画面の「設問」の曜日ごとの欄 |
| 水曜の3つ目の QUEST | シートの文字が崩れていたので「怖さが出る0.5秒前を捕まえる」（書き方シートの「怖さの0.5秒前」から） | 親の画面の「設問」 |
| 声かけの時刻 | 子どもごとに 7:00・21:00（15分刻みで変えられる） | 親の画面の「子どもと LINE」 |
| 土日 | 声かけなし。曜日を選べば金曜分などを後から書ける | 入力ページ上部の曜日ボタン |

## 手元での確認

```bash
node tests/gas.test.js
cd web && python3 -m http.server 8765
# → http://localhost:8765/?mock=1&slot=morning （LINE も Apps Script も使わない見本モード。&kids=1 で1人、&kids=0 で未登録）
# 親の画面は、リポジトリの直下で同じように立てて http://localhost:8765/preview/parent.html
```
