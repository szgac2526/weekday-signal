# WEEKDAY SIGNAL セットアップ手順（あなたの作業）

所要時間：**80〜110分**（初めての場合。親の画面とスタンプを含む）。すべて無料の範囲で終わります。

画面の名前やボタンの位置は、LINE と Google が時々変えます。この手順と違うところがあったら、近い名前のものを探してください。どうしても見つからなければ、その画面のスクリーンショットを送ってください。

---

## 全体の形

```
息子さんの LINE
  │ ① 下のメニュー「朝」「夜」をタップ
  ▼
入力ページ（LINE の中で開く。GitHub Pages に置く）
  │ ② 送信
  ▼
Google Apps Script（Google が無料で動かしてくれる小さなプログラム）
  │ ③ スプレッドシートに1日1行で書く
  │ ④ 平日 7時・21時にボットから声かけ
  ▼
Google スプレッドシート ──┬── 親の画面（Google でログイン。手順11）
                          └── Excel でも落とせる
スタンプ：朝と夜の両方を書いた平日に ★ 1つ。月の平日ぶん全部そろうと 🎁（手順12）
```

## 用意するもの

- Google アカウント（あなたのもの）
- LINE アカウント（あなたのもの。公式アカウントの管理に使います）
- GitHub アカウント（入力ページを置く場所。ページの中身に個人情報は入りません）
- 息子さんの LINE

## 手順の順番（大事）

手順の途中で出てくる値を、あとの手順で使います。**上から順に**進めてください。
途中で控える値は、下の「控えメモ」にまとめて書いておくと迷いません。

| 控えメモ | 手に入る手順 | 使う手順 |
| --- | --- | --- |
| 入力ページの URL | 1 | 4 |
| チャネルアクセストークン | 3 | 6 |
| LINE ログインのチャネルID | 4 | 6 |
| LIFF ID ／ LIFF URL | 4 | 5・6・8 |
| 合言葉（WEBHOOK_KEY） | 6 で自分で決める | 6・7 |
| Apps Script の Web アプリ URL | 6 | 5・7 |

## 1. 入力ページを公開する（GitHub Pages）・5分

リポジトリ `szgac2526/weekday-signal` は用意済みです。入力ページ（`web/` フォルダ）だけを公開する設定も入っています。

1. [リポジトリの Settings → Pages](https://github.com/szgac2526/weekday-signal/settings/pages) を開きます。
2. 「Build and deployment」の「Source」を **GitHub Actions** にします（保存ボタンはありません。選ぶだけです）。
3. [Actions](https://github.com/szgac2526/weekday-signal/actions) を開き、左の「Pages」→ 右の「Run workflow」→「Run workflow」を押します。
4. 1〜2分で緑のチェックが付きます。次の URL が入力ページです。控えてください。
   `https://szgac2526.github.io/weekday-signal/`
   - 開くと「開けませんでした」と出ますが、いまはそれで正常です（LIFF ID をまだ入れていないため）。

**公開されるのは `web/` の中（入力ページのプログラムと設問）だけです。** 記録はスプレッドシートに入るので、ここには残りません。リポジトリそのものも公開になっています（無料で GitHub Pages を使うため）。秘密の値（トークンや合言葉）は Apps Script の設定に入れるので、リポジトリには一切入りません。

## 2. LINE 公式アカウントを作る・10分

1. [LINE for Business の LINE公式アカウント](https://www.linebiz.com/jp/entry/) から、未認証アカウントを無料で作ります。
   - アカウント名の例：`WEEKDAY SIGNAL`
   - 業種は「個人」に近いものを選んで構いません。
2. LINE Official Account Manager（管理画面）にログインします。
3. 右上の「設定」→「Messaging API」→「Messaging API を利用する」を押します。
   - 「プロバイダー」を聞かれたら、新しく作ります（例：`weekday-signal`）。
   - **このプロバイダー名は手順4でも使います。必ず同じものを選んでください。**
4. 「設定」→「応答設定」で、次のようにします。
   - 応答メッセージ：**オフ**（決まった自動返信が、ボットの返事と二重に出るのを防ぐため）
   - あいさつメッセージ：**オフ**（ボットが代わりに送ります）
   - Webhook：**オン**
5. 「設定」→「アカウント設定」で「検索結果への表示」を**オフ**にします。知らない人に友だち追加されないようにするためです。

## 3. ボットの鍵を取る（チャネルアクセストークン）・5分

1. [LINE Developers コンソール](https://developers.line.biz/console/) に、同じ LINE アカウントでログインします。
2. 手順2で作ったプロバイダーを開くと、公式アカウントと同じ名前の「Messaging API」チャネルがあります。開いてください。
3. 「Messaging API設定」タブの一番下、「チャネルアクセストークン（長期）」の「発行」を押します。
4. 出てきた長い文字列を控えます。**これは秘密の値です。** 人に見せたり、GitHub に置いたりしないでください。

## 4. LINE の中で入力ページを開く設定（LIFF）・10分

1. LINE Developers で、**手順3と同じプロバイダー**の中に「新規チャネル作成」→「**LINEログイン**」を作ります。
   - チャネル名の例：`WEEKDAY SIGNAL 入力`
   - アプリタイプ：「ウェブアプリ」にチェック
   - **プロバイダーを同じにする理由**：違うプロバイダーにすると、ボットと入力ページとで同じ人が別の ID になり、記録が結びつかなくなります。
2. 作ったチャネルの「チャネル基本設定」にある**チャネルID**（数字）を控えます。
3. 同じ画面で「リンクされたLINE公式アカウント」に、手順2の公式アカウントを選びます。
4. 「LIFF」タブ →「追加」で、次のように入れます。
   - LIFFアプリ名：`WEEKDAY SIGNAL`
   - サイズ：**Full**
   - エンドポイントURL：手順1で控えた入力ページの URL
   - Scope：**openid** と **chat_message.write** にチェック（profile もチェックして構いません）
     - openid は、送ったのが誰かを確かめるために使います
     - chat_message.write は、送信後にトークへ「朝のチェック完了」を残すために使います
   - 友だち追加オプション：**On (Aggressive)**
5. できあがった **LIFF ID**（`2001234567-AbCdEfGh` のような形）と **LIFF URL**（`https://liff.line.me/…`）を控えます。
6. チャネル名の横の「開発中」を「**公開**」に切り替えます。
   - 「開発中」のままだと、あなた以外（息子さん）がログインできません。

## 5. 入力ページに値を入れる・5分

[`web/config.js`](https://github.com/szgac2526/weekday-signal/edit/main/web/config.js) の2行を書き換えて「Commit changes」を押します（GitHub の画面で直接編集できます）。押すと1〜2分で入力ページに反映されます。

```js
window.WS_CONFIG = {
  LIFF_ID: "手順4で控えた LIFF ID",
  GAS_URL: "手順6で控える Web アプリ URL",   // ← 手順6のあとで入れる
};
```

**GAS_URL はまだ無いので、いまは LIFF_ID だけ入れて、手順6のあとにもう一度ここへ戻ります。**

## 6. 記録先のスプレッドシートとプログラム・20分

1. Google ドライブで新しいスプレッドシートを作ります。名前の例：`WEEKDAY SIGNAL 記録`
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 左の「プロジェクトの設定」（歯車）で、「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れます。
4. 左の「エディタ」に戻り、次の2つを貼り替えて保存します。
   - `コード.gs` の中身を全部消して、私の `gas/Code.gs` を貼る
   - 左の「ファイル」の「＋」→「スクリプト」で `Shared` という名前のファイルを足し、私の `gas/Shared.gs` を貼る
   - `appsscript.json` の中身を全部消して、私の `gas/appsscript.json` を貼る
5. 「プロジェクトの設定」→ 一番下の「スクリプト プロパティ」に、次の4つを追加します。

   | プロパティ | 値 |
   | --- | --- |
   | `LINE_CHANNEL_ACCESS_TOKEN` | 手順3で控えたトークン |
   | `LINE_LOGIN_CHANNEL_ID` | 手順4で控えたチャネルID（数字） |
   | `LIFF_URL` | 手順4で控えた LIFF URL（`https://liff.line.me/…`） |
   | `WEBHOOK_KEY` | 自分で決めた合言葉。英数字20文字くらい（例：`k8Qz2mPw7Lr4Xt9Vn3Bs`）。**人に教えない** |

6. エディタ上部で関数 `setup` を選んで「実行」を押します。
   - 初回は「承認が必要です」と出ます。自分の Google アカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」を押します。自分で作ったプログラムなので、この警告が出るのは正常です。
   - スプレッドシートに `records`・`users`・`gifts` の3つのシートができれば成功です。
   - 平日の朝7時と夜21時に声かけを送る予約も、ここで入ります。
7. 右上の「デプロイ」→「新しいデプロイ」を開き、種類に「ウェブアプリ」を選びます。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」を押すと出る **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を控えます。
8. **手順5に戻り**、`config.js` の `GAS_URL` にこの URL を入れて、GitHub に上げ直します。

> 「アクセスできるユーザー：全員」でも、送信は LINE のログインで本人確認をしてから受け付けます。登録されていない人の送信は捨てます。

## 7. ボットと Apps Script をつなぐ（Webhook）・5分

1. LINE Developers の Messaging API チャネル →「Messaging API設定」→「Webhook設定」を開きます。
2. Webhook URL に、手順6で控えた Web アプリ URL の後ろへ `?key=合言葉` を付けたものを入れます。
   `https://script.google.com/macros/s/…/exec?key=k8Qz2mPw7Lr4Xt9Vn3Bs`
3. 「Webhookの利用」を**オン**にします。
4. 「検証」ボタンは、Apps Script の仕組み上「失敗」と出ることがあります。その場合も、手順9の動作確認で返事が来れば問題ありません。

## 8. トーク画面下のメニューを作る（リッチメニュー）・10分

1. LINE Official Account Manager →「ホーム」→「リッチメニュー」→「作成」を開きます。
2. タイトル：`朝・夜のチェック`、表示期間：今日から数年後まで、メニューバーのテキスト：`朝・夜のチェック`、「メニューのデフォルト表示」：**表示する**
3. 「テンプレートを選択」で、**小さいサイズの「左右に2分割」**を選びます。
4. 「画像を作成」→「背景画像をアップロード」で、私の `assets/richmenu.png`（横2500×縦843）を選びます。
5. アクションを次のようにします。
   - A（左）：タイプ「リンク」、URL：`LIFF URL?slot=morning`
   - B（右）：タイプ「リンク」、URL：`LIFF URL?slot=night`
   - 例：`https://liff.line.me/2001234567-AbCdEfGh?slot=morning`
6. 「保存」を押します。

## 9. 動作確認（あなたのスマホで）・10分

1. 公式アカウントを、**あなた自身の LINE** で友だち追加します（管理画面の「友だち追加ガイド」に QR コードがあります）。
   - 「友だち追加ありがとう！」とボタンが届けば、Webhook はつながっています。
   - スプレッドシートの `users` シートに、あなたの行が1行できます。
2. トーク画面下の「朝」を押す → 入力ページが開く → いくつか選んで「アンテナON！」を押す。
   - トークに「【朝のチェック完了】…」が残り、ボットから返事が来れば成功です。
   - `records` シートに今日の行ができます。
3. 「夜」も同じように試します。朝に選んだ QUEST が上に表示され、同じ行の右側が埋まります。
4. 確認が終わったら、`users` シートの**あなたの行の「有効」を FALSE** にします。これで声かけがあなたに届かなくなります。
   - `records` シートの試しの行は、消して構いません。

## 10. 息子さんたちに使ってもらう・1人5分

**2人とも、同じ公式アカウントを友だち追加するだけです。**記録・スタンプ・ギフトは LINE のアカウントごとに分かれるので、ボットや入力ページを2つ作る必要はありません。

1. 1人目の LINE で、QR コードから友だち追加してもらいます。
2. 「朝」を一度一緒に押して、入力ページを開くところまで見てあげてください。
   - 初回だけ「アクセスの許可」を聞かれるので、「許可する」を押します。
3. `users` シートに1人目の行ができたら、2人目も 1〜2 を同じように。
4. `users` シートの**「名前」は LINE の表示名**で入ります。ニックネームや絵文字のままだと親の画面で見分けにくいので、必要なら**名前のセルを書き換えて**ください（「たかまさ」「ゆうま」など）。書き換えた名前は、その後の記録と親の画面に使われます。
5. 翌平日の朝7時から、まだ書いていない子にだけ声かけが届きます。

**1台の携帯を2人で使う場合は、この仕組みでは分けられません。**記録は LINE のアカウントで見分けているので、同じ LINE で書くと1人分になります。それぞれ自分の LINE がある前提です。

## 11. 親の画面を作る・15分

**ボットとは別の Apps Script** として作ります。ボットは誰でも呼べる形で公開しているので、同じところに親の画面を置くと Google のログインを求められないためです。

1. [script.google.com](https://script.google.com/) を開き、「新しいプロジェクト」を作ります。名前の例：`WEEKDAY SIGNAL 親の画面`
2. 手順6-3と同じく、`appsscript.json` を表示する設定にします。
3. 次の3つを貼ります。
   - `コード.gs`：私の `gas-parent/Code.gs`
   - 「＋」→「スクリプト」で `Shared`：私の `gas-parent/Shared.gs`（ボットに貼ったものと**同じ中身**です）
   - 「＋」→「HTML」で `Index`：私の `gas-parent/Index.html`
   - `appsscript.json`：私の `gas-parent/appsscript.json`
4. 「プロジェクトの設定」→「スクリプト プロパティ」に追加します。

   | プロパティ | 値 |
   | --- | --- |
   | `SHEET_ID` | 記録のスプレッドシートの ID。URL の `/d/` と `/edit` の間の長い文字列 |
   | `LINE_CHANNEL_ACCESS_TOKEN` | （任意）手順3のトークン。入れると「贈った」を押したとき、息子さんの LINE に知らせます |
   | `GIFT_LABEL`・`STAMP_GOAL` | （任意）手順12で決めた値。ボットと同じ値にします |

5. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」で、次のようにします。
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**Google アカウントを持つ全員**
6. 出てきた URL をスマホのホーム画面やブックマークに入れます。開くと Google のログインを求められ、初回は「許可」を聞かれます。

**誰が見られるか**
- 画面は**見ている人の Google アカウントで**スプレッドシートを開きます。なので、**記録のスプレッドシートを共有された人だけが見られます。** URL を知っていても、共有されていない人には「権限がありません」と出ます。
- もう1人の親にも見せるときは、スプレッドシートの「共有」でその人を追加し、親の画面の URL を送ります。
- 「贈った」ボタンを押すには、共有の権限が「**編集者**」である必要があります。「閲覧者」は見るだけです。

## 12. スタンプとギフト・5分

**決まりごと**
- 朝と夜の**両方**を書いた平日に、★ が1つ付きます。
- 目標は「**その月の平日の数**」（10月なら22）。祝日も平日として数えます。書き忘れた日は、入力ページ上部の曜日ボタンで1週間前まで後から書けます。
- 目標に届くと、息子さんには LINE で「🎁 そろった！」とお祝いのスタンプが届きます。親には画面にお知らせが出ます（設定すれば LINE でも届きます）。
- スタンプもギフトも**1人ずつ**です。2人とも達成すれば 1,000円分 × 2人。片方だけ達成しても、もう片方には何も届きません。
- **ギフトそのものは、自動では贈れません。** LINE のボットからは、LINE ギフトなどを買って贈る操作ができないためです。親が LINE ギフトや Amazon ギフトなどで贈り、親の画面で「贈った」を押すと、息子さんに「🎁 贈ったよ！」と届きます。

**変えたいときは**（ボットの Apps Script と親の画面の両方のスクリプト プロパティに、同じ値を入れる）

| プロパティ | 例 | 意味 |
| --- | --- | --- |
| `STAMP_GOAL` | `20` | 目標を平日の数より少なくする（祝日や行事がある月に） |
| `GIFT_LABEL` | `1,000円分` | メッセージの中のごほうびの言い方 |
| `PARENT_LINE_USER_ID` | `U1234…` | （ボット側だけ）達成を親の LINE にも送る。`users` シートのあなたの行の LINEユーザーID をコピー |

- 親の画面の上部に**2人の名前のボタン**が並び、それぞれの今月のスタンプ数が出ます。🎁 は「達成したがまだ贈っていない」、✓ は「贈った」の印です。押すとその子の記録に切り替わります。
- 息子さんは、トークで「スタンプ」と送れば、いつでも今月のスタンプカードを見られます。
- スタンプが5個たまるごとに、ボットからお祝いの LINE スタンプが届きます。

## 日々の見方（親）

- **親の画面（手順11）**：スタンプカード、今月の数字、体・気分・元気の推移、よく選んだアンテナ、毎日の記録（俺のKEY・宝物）が1画面で見られます。
- スプレッドシートの `records` シートに、**1日1行**で溜まります。朝の分と夜の分は同じ行に入ります。
- Excel で欲しいときは「ファイル → ダウンロード → Microsoft Excel（.xlsx）」。
- 週のまとめやグラフが欲しくなったら言ってください。同じスプレッドシートに足せます。

## 変えたくなったとき

| 変えたいこと | どこを変えるか |
| --- | --- |
| 設問・選択肢 | `questions.json`（GitHub）。上げ直せば次に開いたときから変わります |
| 声かけの時刻 | `Code.gs` の `setup` の `atHour(7)`・`atHour(21)` を変えて、`setup` をもう一度実行 |
| 声かけを止めたい人 | `users` シートの「有効」を FALSE |
| `Code.gs` を直したとき | 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」。**URL は変わりません** |

## うまくいかないとき

| 症状 | 見るところ |
| --- | --- |
| 友だち追加しても返事が来ない | 手順7の Webhook URL（`?key=` の合言葉がスクリプト プロパティと同じか）、Webhook の利用がオンか、応答設定の Webhook がオンか |
| 入力ページが「開けませんでした」 | `config.js` の LIFF_ID、LIFF のエンドポイント URL が手順1の URL と同じか |
| 送信すると「この LINE アカウントは登録されていません」 | 友だち追加の時点で Webhook がつながっていなかった。一度ブロック→ブロック解除すると登録されます |
| 送信すると「ログインの確認に失敗しました」 | スクリプト プロパティの `LINE_LOGIN_CHANNEL_ID` が、手順4のチャネルIDと同じか |
| 息子さん（片方だけでも）入力ページに入れない | 手順4-6 で LINE ログインチャネルを「公開」にしたか |
| 親の画面で「権限がありません」 | その Google アカウントに、記録のスプレッドシートが共有されているか。親の画面の `SHEET_ID` が合っているか |
| 「贈った」を押すと失敗する | 共有の権限が「編集者」か |
| スタンプが付かない | 朝と夜の**両方**を、同じ日付で書いたか（夜だけでは付きません） |
| お祝いのスタンプ（絵）が来ない | LINE 側でそのスタンプが使えない場合、文字だけで返事をする作りです。困らなければそのままで構いません |
| 声かけが来ない | Apps Script の「トリガー」（時計のアイコン）に2つあるか。無ければ `setup` を実行し直す |

## 費用と上限

- Google（スプレッドシート・Apps Script）・GitHub Pages：0円
- ギフト代：月1,000円（達成した月だけ）
- LINE 公式アカウント（無料プラン）：ボットから**送る**メッセージに月の上限があります。声かけは「平日2通×約22日×2人＝**月88通前後が最大**」で、まだ書いていない子にだけ送るので実際はこれより少なくなります。息子さんの入力への**返事**（スタンプカード・お祝いを含む）は上限に数えません。「贈った」の知らせと、親への達成の知らせは2人で月2〜4通です。
  - 上限の通数は改定されることがあるので、作成時に管理画面の「プラン」で確かめてください。
