## A. ボット（Apps Script）を更新する・15分

ボットの Apps Script は、**記録のスプレッドシート**から開きます（スプレッドシートのメニュー「拡張機能」→「Apps Script」）。

### A-1. `コード.gs` を貼り替える
1. 左の「ファイル」一覧で `コード.gs`（または `Code.gs`）を開く。
2. エディタの中をクリックし、**すべて選択**（Mac：⌘+A ／ Windows：Ctrl+A）→ Delete で消す。
3. GitHub の `gas/Code.gs` をコピーして、貼り付ける。
4. **保存**（Mac：⌘+S ／ Windows：Ctrl+S、または上のフロッピーのアイコン）。
   - ファイル名の横の丸印（未保存の印）が消えれば保存できています。

### A-2. `Shared.gs` を貼り替える
1. 左の一覧で `Shared.gs` を開く。
2. A-1 と同じく、すべて選択 → 消す → GitHub の `Shared.gs` を貼る → 保存。

### A-3. `setup` を実行する（声かけの予約を入れ替える）
1. エディタ上部の「実行」ボタンの右にある、**関数の選択欄**で `setup` を選ぶ。
2. 「実行」を押す。
3. 「承認が必要です」と出たら、自分の Google アカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」。
   - 何も聞かれずに終わることもあります。どちらでも問題ありません。
4. 下の「実行ログ」に **「実行完了」** と出れば成功です。
   - この操作で、7時・21時の古い予約が消え、**15分ごとの見回り（`tick`）** が1つ入ります。
   - シートの記録は消えません。`children` シートの見出しに「朝の通知」「夜の通知」が足されます。

### A-4. 予約を確かめる
1. 左の **時計のアイコン（トリガー）** を開く。
2. 次の1行だけがあれば正しい状態です。

   | 実行する関数 | イベントのソース | 種類 |
   | --- | --- | --- |
   | `tick` | 時間主導型 | 分ベースのタイマー（15分おき） |

   - `sendMorningReminder`・`sendNightReminder` が残っていたら、A-3 をもう一度実行してください。

### A-5. 新しいバージョンでデプロイする（**URL は変えない**）
1. 右上の「デプロイ」→「**デプロイを管理**」。
2. 左に出ている今のデプロイを選び、右上の **鉛筆（編集）** を押す。
3. 「バージョン」を **「新バージョン」** にする。説明は空でも構いません（例：`2026-10-09 黒基調・通知時刻`）。
4. 「デプロイ」を押す。
5. 出てきた URL が、`config.js` の `GAS_URL`（`…IMDpf8/exec`）と**同じ**であることを確かめる。

> ⚠ **「新しいデプロイ」は押さないでください。**URL が変わり、入力ページの `config.js` と LINE の Webhook URL の両方を直す必要が出ます。

### A-6. 動いているか確かめる
1. ブラウザで Web アプリの URL（`…/exec`）を開く → **`Aestus is running`** と出れば OK。
   - 「ファイルを開くことができません」と出たら、シークレットウィンドウで開き直してください（Google に複数ログインしていると出ます）。

## B. 親の画面（Apps Script）を更新する・10分

親の画面の Apps Script は、[script.google.com](https://script.google.com/) の一覧から開きます（名前の例：`Aestus 親の画面`）。

### B-1. 3つのファイルを貼り替える
A-1 と同じ手順（すべて選択 → 消す → 貼る → 保存）で、次の3つを貼り替えます。

| 左の一覧のファイル | 貼るもの |
| --- | --- |
| `コード.gs`（`Code.gs`） | GitHub の **`gas-parent/Code.gs`** |
| `Index.html` | GitHub の `gas-parent/Index.html` |
| `Shared.gs` | GitHub の `Shared.gs`（A-2 と同じもの） |

### B-2. 新しいバージョンでデプロイする
A-5 と同じです。「デプロイを管理」→ 鉛筆 → **「新バージョン」** →「デプロイ」。親の画面の URL は変わりません。

### B-3. 通知の時刻を決めて保存する
1. 親の画面を開く（すでに開いていたら再読み込み）。
2. 左上が **「Aestus」**、タブに「子どもと LINE」があることを確かめる。
3. 「**子どもと LINE**」を開く。各行に「**朝の通知**」「**夜の通知**」の欄が出ています。
4. 子どもごとに時刻を選ぶ。
   - 15分刻み（5:00〜23:45）。「通知しない」も選べます。
   - 何も変えなければ朝 7:00・夜 21:00 です。
5. 「**保存**」を押す。上に「保存しました。」と出れば完了です。
   - **今いる子どもも、一度は保存してください。**保存すると、スプレッドシートの `children` シートの F 列・G 列（朝の通知・夜の通知）に時刻が入ります。
   - 「変更できませんでした」と出たら、そのアカウントへのスプレッドシートの共有が「閲覧者」になっています。「編集者」にしてください。

**通知の決まりごと**
- 平日だけ。その時刻までに、その時間帯（朝・夜）をまだ書いていなければ届きます。
- 見回りが15分ごとなので、**最大15分ほど遅れます。**
- 時刻を**3時間**過ぎても書いていなければ、その日はもう送りません（止まっていたあとに、昼に朝の声かけが届かないように）。
- 兄弟で同じ LINE・同じ時刻なら1通にまとまり、まだ書いていない子の名前が入ります。時刻を別にすれば別々に届きます。

## C. トーク画面下のメニュー画像を差し替える・5分

1. GitHub から `richmenu.png` をダウンロードする（0. の表のリンク → 右上の「…」→「Download」）。
2. [LINE Official Account Manager](https://manager.line.biz/) で Aestus を開く。
3. 左のメニュー「**トークルーム管理**」→「**リッチメニュー**」。
4. 使っているリッチメニュー（ステータス「表示中」）を開く。
5. 「コンテンツ設定」の「**画像を変更**」→「画像をアップロード」で `richmenu.png` を選ぶ。
6. **アクションはそのまま**にします（左が `…?slot=morning`、右が `…?slot=night` のリンク）。消えていたら入れ直してください。
   - 左（AM WARM-UP）：タイプ「リンク」、URL は LIFF URL の後ろに `?slot=morning`
   - 右（PM COOL-DOWN）：タイプ「リンク」、URL は LIFF URL の後ろに `?slot=night`
7. 「保存」。
   - スマホの LINE に反映されるまで、数分かかることがあります。トーク画面を開き直すと早く変わります。

## E. うまくいかないとき

| 症状 | 原因と直し方 |
| --- | --- |
| 送ったあとの返事が「どっちを記録する？」のボタンだけ | ボットが古いまま。A-1〜A-2 の保存と、**A-5 の「新バージョン」でのデプロイ**をしたか |
| 返事に「WARM-UP 完了」が来るが、カードが白い・★が出る | 同上（保存しただけで、デプロイが古い） |
| 通知が来ない | ① A-4 のトリガーに `tick` があるか ② その子の時刻が「通知しない」でないか ③ 平日か ④ その時間帯をもう書いていないか ⑤ 時刻から3時間を過ぎていないか ⑥ その LINE を「止める」にしていないか |
| 通知が2回来る | LINE Developers の「Webhookの再送」がオンになっていないか（オフにする） |
| 親の画面に「朝の通知」の欄が無い | 親の画面の `Index.html` が古い、または B-2 のデプロイをしていない |
| 親の画面で「変更できませんでした」 | スプレッドシートの共有が「閲覧者」。「編集者」にする |
| `setup` で「承認が必要です」から先に進めない | 「詳細」→「（安全ではないページ）に移動」を押す。自分で作ったプログラムなので、この警告は正常 |
| 「ファイルを開くことができません」（Google ドライブの画面） | Google に複数ログインしている。シークレットウィンドウで、使うアカウント1つだけで開く |
| 入力ページに「設定（config.js）が読めませんでした」 | 少し待って開き直す。続くときは `web/config.js` の値が `"` で囲まれているか |

## F. これからコードを直したときの共通の手順

| 直したもの | やること |
| --- | --- |
| `web/` の中（入力ページ・設問の初期値） | GitHub に push するだけ。1〜2分で公開される |
| `gas/` の中（ボット） | 変わったファイルを貼り替え → 保存 → **デプロイを管理 → 鉛筆 → 新バージョン** |
| `gas-parent/` の中（親の画面） | 同上 |
| `Shared.gs` | **ボットと親の画面の両方**に貼り替える（片方だけだと数え方が食い違う） |
| 声かけの仕組み・シートの列を変えたとき | 上に加えて、ボットで `setup` をもう一度実行 |

- **いつも「新バージョン」。「新しいデプロイ」は使わない**（URL が変わるため）。
- 秘密の値（トークン・合言葉）はスクリプト プロパティにあり、コードの貼り替えでは消えません。
